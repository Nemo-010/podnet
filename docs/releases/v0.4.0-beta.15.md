A prerelease of `podnet`, for tests. It follows v0.4.0-beta.14.

## Binaries

| File | System |
| --- | --- |
| `podnet-x86_64-unknown-linux-musl` | Linux x86-64 |
| `podnet-aarch64-unknown-linux-musl` | Linux ARM64 |
| `podnet-armv7-unknown-linux-musleabihf` | Linux ARMv7 (32-bit, hard float) |
| `podnet-arm-unknown-linux-musleabihf` | Linux ARMv6 (32-bit, hard float) |
| `podnet-i686-unknown-linux-musl` | Linux x86 (32-bit) |
| `podnet-riscv64gc-unknown-linux-musl` | Linux RISC-V 64 |
| `podnet-loongarch64-unknown-linux-musl` | Linux LoongArch64 |
| `podnet-powerpc64le-unknown-linux-musl` | Linux POWER, little-endian |

Each binary is static (musl). It needs no C library on the host.
`podnet.1` is the manual page. `llms.txt` and `llms-full.txt` are the
manual and the documents as plain text. `pod-report.schema.json` is the JSON
Schema of `podnet pod --report`. `SHA256SUMS` lists each file.

The image is `ghcr.io/podutils/podnet:v0.4.0-beta.15` (also `:beta`).

## Check a download

```sh
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify podnet-x86_64-unknown-linux-musl --repo PodUtils/podnet
cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity https://github.com/PodUtils/podnet/.github/workflows/release.yml@refs/tags/v0.4.0-beta.15 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sh scripts/rebuild.sh v0.4.0-beta.15   # rebuild and compare (x86_64, aarch64)
```

`podnet update` does the first three checks itself.

## Breaking

* `podnet warp proxy` checks its rules (`-r`, `--rules-file`) for shadowed rules, as `podnet pod -r` and the router do:
  an earlier rule that matches each target of a later rule of another action gives a warning. A shadowed `reject` rule
  is an error (exit 64); `--allow-shadowed-rules` makes it a warning. A reload of `--rules-file` with such a rule keeps
  the rules before (T-242, GitHub #433).

## Changes for a tester

* `podnet forward --name NAME=HOST:PORT` gives each name an address of 127.0.0.0/8, and the DNS door answers the name
  with it: a client that cannot edit its hosts file reaches the target by its name. `--alias-port` sets the local port
  (T-404, GitHub #601).
* A door of `podnet route` takes a rate, a quota, a period and `on_exhaust`; the usage is kept across a restart in
  `router-usage.json` (T-405, GitHub #602).
* `podnet link exec-status:` sends the stdout, the stderr and the exit status of the program as records;
  `podnet link dial --status` exits with the status of the program (T-403, GitHub #600).
* `podnet relay` as a node: when the relay answers 409 (it holds the name of a lost socket of the node), podnet says so
  and, with a pair directory, takes the next stored pair (T-410).
* `podnet ssh-relay` asks for the remote forward on `localhost`, as OpenSSH does: localhost.run serves the origin
  (`--service localhost-run`, port 80 from `pod-services`) (T-418, T-416).
* The private files of podnet (the record and the secrets of an instance, the env file of autostart, the key record of
  a link alias) are replaced with a sync of the file and of its directory: a power cut leaves the old file or the new
  one, not an empty one (T-417).
* `podnet ssh-relay` and `podnet warp license` have scenarios in `live.yml`: their help has no "Experimental:" mark
  (T-398). `podnet net tailscale` stays experimental.
* The shared crates of PodUtils/podcrates are at `v0.67.0` (T-137).

## What to report

Open an issue in `PodUtils/podnet` with the output of `podnet doctor --json`
and `podnet pod doctor --json`, the command, and the stderr of the command
with `-v`. The test guide is GitHub #89.

## Limits

* This is a beta. Each item of Breaking can change again before the stable
  release.
* No crates.io release of `podnet` exists.
* The Rekor inclusion proof is not checked by `podnet update`.
* `rsa` 0.10.0-rc.18 (pinned by russh) has the advisory RUSTSEC-2023-0071, a timing
  leak of an RSA private key. podnet makes Ed25519 keys. Give podnet no RSA key (T-326).
* Experimental (no scenario of the release binary): `podnet net tailscale`, `podnet ssh-relay` and `podnet warp license`.
  Only the tests with stand-ins check them.
* The netlink answer of the vnet shim was not measured with libtorrent or qBittorrent. A program that reads a netlink
  socket with `read(2)` after `write(2)` gets no answer.
* The limits of v0.4.0-beta.13 stand.
