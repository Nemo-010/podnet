A prerelease of `podnet`, for tests. It follows v0.4.0-beta.13.

## Binaries

| File | System |
| --- | --- |
| `podnet-x86_64-unknown-linux-musl` | Linux x86-64 |
| `podnet-aarch64-unknown-linux-musl` | Linux ARM64 |
| `podnet-armv7-unknown-linux-musleabihf` | Linux ARMv7 (32-bit, hard float) |
| `podnet-arm-unknown-linux-musleabihf` | Linux ARMv6 (32-bit, hard float) |
| `podnet-i686-unknown-linux-musl` | Linux x86 (32-bit) |
| `podnet-riscv64gc-unknown-linux-musl` | Linux RISC-V 64 |
| `podnet-loongarch64-unknown-linux-musl` | Linux LoongArch64 |
| `podnet-powerpc64le-unknown-linux-musl` | Linux POWER, little-endian |

Each binary is static (musl). It needs no C library on the host.
`podnet.1` is the manual page. `llms.txt` and `llms-full.txt` are the
manual and the documents as plain text. `pod-report.schema.json` is the JSON
Schema of `podnet pod --report`. `SHA256SUMS` lists each file.

The image is `ghcr.io/podutils/podnet:v0.4.0-beta.14` (also `:beta`).

## Check a download

```sh
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify podnet-x86_64-unknown-linux-musl --repo PodUtils/podnet
cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity https://github.com/PodUtils/podnet/.github/workflows/release.yml@refs/tags/v0.4.0-beta.14 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sh scripts/rebuild.sh v0.4.0-beta.14   # rebuild and compare (x86_64, aarch64)
```

`podnet update` does the first three checks itself.

## Breaking

* `podnet components --json` has no field `portable`, and the build has no Cargo feature `portable`: the feature gated
  no code. The owner rules Linux only (T-396).
* `podnet man --json` and `--help --json` give the model of `pod-manual` (schema 1) (T-359).
* `podnet pod --backend netns-kernel` binds its listeners in the new namespace to 127.0.0.1 ports 61001 to 61003. A
  program in the pod cannot bind these ports of 127.0.0.1 (T-384).
* The help of a command that no scenario of the release binary runs starts with "Experimental:" (T-358).

## Changes for a tester

* The release gate (T-358): this binary ran the lane of `scripts/lab-lane.sh` in the labs of `pod-lab` (restricted
  hosts: no `bind` of `AF_INET`, no `listen`, no UDP, Landlock, no `/proc`, a proxy only, IPv6 only, and more), as a user
  that is not root. The section "The release gate" below lists each row. The section "The scenarios of each command"
  lists the experimental commands: a command with no scenario of the release binary.
* The vnet shim (`podnet net shim`): a program that enumerates its interfaces (`NETLINK_ROUTE`, `getifaddrs`,
  `if_nameindex`) sees `lo` and `vnet0` with the virtual address, not the host (T-392, GitHub #599);
  `PODNET_VNET_HOST_NETLINK=1` gives the host's view. A bind to `0.0.0.0` or `::` takes the virtual address (T-391). The
  record locks of `fcntl` work (T-390). `PODNET_VNET_FORWARD` sends a TCP destination to a unix socket (T-357). An
  IPv4-mapped IPv6 address meets its IPv4 listener (T-356).
* `podnet pod`: the netns-kernel backend works on a host that refuses `getsockname` (T-384). The fake DNS answers DNS
  over TCP, so name resolution works where UDP is refused (T-383). `auto` takes seccomp where each TCP connect is refused
  in each namespace (T-382). A unix listener binds under Landlock (T-379). `pod doctor` names a refused socket of the
  interface ioctls (T-381).
* A quick tunnel over `quic+warp` reconnects when its WARP session closes; before, it could stay down until a stop
  (T-402).
* `podnet connect` dials the WebSocket again (3 tries) after a failure that can pass, in place of a reset of the
  local connection (T-407).
* `--detach` and `autostart` work on a host with no `/proc`: podnet finds its own file from `argv[0]` (T-401).
* `scripts/install.sh` is the installer core of PodUtils/podcrates: hermetic and idempotent; it checks the cosign
  signature of `SHA256SUMS` when cosign is installed (`PODNET_COSIGN`) (T-360, T-389, T-394).
* `podnet man` and the help come from `pod-manual` of PodUtils/podcrates (T-359).
* The shared crates of PodUtils/podcrates are at `v0.63.0` (T-137).

## What to report

Open an issue in `PodUtils/podnet` with the output of `podnet doctor --json`
and `podnet pod doctor --json`, the command, and the stderr of the command
with `-v`. The test guide is GitHub #89.

## Limits

* This is a beta. Each item of Breaking can change again before the stable
  release.
* No crates.io release of `podnet` exists.
* The Rekor inclusion proof is not checked by `podnet update`.
* `rsa` 0.10.0-rc.18 (pinned by russh) has the advisory RUSTSEC-2023-0071, a timing
  leak of an RSA private key. podnet makes Ed25519 keys. Give podnet no RSA key (T-326).
* Experimental (no scenario of the release binary): `podnet net tailscale`, `podnet ssh-relay` and `podnet warp license`.
  Only the tests with stand-ins check them.
* The netlink answer of the vnet shim was not measured with libtorrent or qBittorrent. A program that reads a netlink
  socket with `read(2)` after `write(2)` gets no answer.
* The limits of v0.4.0-beta.13 stand.
